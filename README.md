# LocalKart

LocalKart is a MERN stack application configured with TypeScript for both frontend and backend. It leverages React, Vite, Tailwind CSS, and Zustand for a modern, responsive user experience.

## Project Structure

```
/localkart
├── backend/           # Express/Mongoose backend with TypeScript
├── frontend/          # React/Vite/Tailwind frontend with TypeScript and Zustand
├── README.md          # Project documentation (this file)
└── .gitignore         # Git ignore patterns
```

## Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn
- MongoDB connection string (local or MongoDB Atlas)

## Getting Started

### 1. Backend Setup

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file from the placeholder and configure your environment variables:
   ```bash
   cp .env.example .env  # Or copy manually
   ```
4. Run the backend in development mode:
   ```bash
   npm run dev
   ```

### 2. Frontend Setup

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the frontend in development mode:
   ```bash
   npm run dev
   ```
